# 02 运行第一个研究实验

## 命令

```powershell
uv run python examples/run_research.py --config config/research.yaml
```

## 预期输出

你会看到类似:

```text
Research report written to D:\Develop\claude\quantify\results\research\20260530_123456
```

如果本地没有真实研究数据,你还会看到 demo data 的提示。这是正常的。

## 发生了什么

1. 系统读取 `config/research.yaml`。
2. 打开或创建 `data_cache/research.db`。
3. 如果缓存为空,生成 demo 数据。
4. 每个月第一个交易日计算因子分数。
5. 选综合分最高的股票。
6. PaperBroker 把目标权重转成模拟买卖。
7. 每天记录净值。
8. 输出研究报告。

## 重要提醒

demo 数据是合成数据,只能用来学习流程。真实研究必须导入或下载真实 A 股数据。

## 导入真实 A 股研究数据

如果要让研究结果有现实意义,先导入真实 A 股缓存:

```powershell
uv run python examples/import_research_data.py --config config/research.yaml --limit 300 --output-dir results/import/latest
```

这会通过 AKShare 下载股票基础信息和日线行情,写入 `data.cache_path` 指向的 SQLite 缓存,并生成:

- `data_import.json`
- `data_import.md`

如果网络失败或没有任何股票成功导入,命令会失败,不会自动退回 demo 数据。

如果你想避免和 demo 缓存混在一起,使用单独的真实研究库:

```powershell
uv run python examples/import_research_data.py --config config/research.yaml --cache data_cache/real_research.db --symbols 600519,000001 --output-dir results/import/smoke
uv run python examples/run_data_audit.py --config config/research.yaml --cache data_cache/real_research.db --output-dir results/import/smoke
```

也可以从本地 CSV 离线导入:

```powershell
uv run python examples/import_research_csv.py --cache data_cache/real_research.db --bars-csv path/to/bars.csv --output-dir results/import/csv
```
