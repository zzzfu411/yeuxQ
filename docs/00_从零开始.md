# 00 从零开始

这份教程假设你没有金融、量化、数据库、Python 项目经验。你只需要会打开 PowerShell,并能复制命令。

## 你会学到什么

1. 股票数据是什么。
2. 回测为什么不能等于赚钱。
3. 什么是因子和多因子策略。
4. 为什么要用本地 SQLite 缓存。
5. 如何跑出第一份研究报告。

## 第一步: 进入项目目录

```powershell
cd D:\Develop\claude\quantify
```

预期结果: 命令行路径变成 `D:\Develop\claude\quantify`。

## 第二步: 安装依赖

```powershell
uv sync
```

这会创建 `.venv` 虚拟环境,并按 `uv.lock` 安装固定版本依赖。

如果你还没有 uv,先安装:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## 第三步: 跑第一份报告

```powershell
uv run python examples/run_research.py --config config/research.yaml
```

如果你没有下载真实 A 股数据,系统会生成 demo 数据。demo 数据只用来学习流程,不代表任何真实收益。

## 第四步: 找报告

报告目录长这样:

```text
results/research/20260530_123456/
```

打开里面的 `html_report.html`,先看:

- 核心指标
- 风险提示
- 最近持仓快照
- `drawdown.png`

下一章读 [01_核心概念.md](01_核心概念.md)。

## 第五步: 做一次实盘前审查

量化系统不能从回测直接跳到实盘。先用新增的审查命令检查这份报告:

```powershell
uv run python examples/run_llm_review.py --report-dir results/research/20260530_123456 --stage paper
```

把目录换成你真实生成的报告目录。运行后重点看:

- `llm_review.md`: 是否 PASS、WATCH 或 BLOCK。
- `llm_prompt.md`: 可以复制给外部 LLM,让它在不越过风控门的前提下帮你质询策略。

继续理解实盘框架请读:

- [05_量化实盘交易心智模型.md](05_量化实盘交易心智模型.md)
- [06_LLM_For_Quantify.md](06_LLM_For_Quantify.md)

## 第六步: 系统学习笔记

跑通系统后,再开始系统读书。逐章笔记入口:

- [notes/README.md](notes/README.md): 学习路线总目录
- [notes/fpp/01_intro.md](notes/fpp/01_intro.md): 预测入门
- [notes/factor/01_factor_basics.md](notes/factor/01_factor_basics.md): 因子投资基础
- [notes/math/01_probability.md](notes/math/01_probability.md): 概率和方差

建议顺序是: 先跑项目,再读概念,最后看数学推导。这样不会一上来就被公式劝退。
