# 术语表

- A 股: 中国大陆交易所上市股票。
- 股票池: 策略允许选择的股票范围。
- 基准: 用来比较策略表现的指数,如沪深300。
- Alpha: 相对市场或基准的超额收益。
- Beta: 跟随市场波动的程度。
- 因子: 给股票打分的规则或变量。
- IC: 因子值和未来收益的相关性。
- RankIC: 因子排名和未来收益排名的相关性。
- 换手率: 一段时间内买卖调整的比例。
- 滑点: 理论价格和实际成交价格的差。
- 佣金: 券商收取的交易费用。
- 印花税: A 股卖出时缴纳的税费。
- T+1: 今天买入的股票,下一个交易日才能卖。
- 涨跌停: A 股单日涨跌幅限制。
- 停牌: 股票暂时不能交易。
- ST: 被特别处理的股票,风险较高。
- 复权: 修正分红送股造成的历史价格跳变。
- 未来函数: 回测中使用了当时不可能知道的未来信息。
- 样本内: 用来开发和调参的历史区间。
- 样本外: 用来验证策略是否更稳健的历史区间。
- 预测: 基于当前可得信息对未来变量做条件估计。详见 [notes/fpp/01_intro.md](notes/fpp/01_intro.md)。
- 条件期望: 在给定信息下的平均预测值,是均方误差下的最优预测。
- 残差: 真实值减预测值,像模型没解释完的尾巴。
- 白噪声: 没有可利用记忆的随机波动,像每次都重新掷硬币。
- 自相关: 当前值和过去值的相关程度。
- 平稳性: 序列的均值、方差和相关结构不随时间明显漂移。
- ARIMA: 用自回归、差分和移动平均误差描述时间序列的模型。
- 回归: 用解释变量拟合或预测目标变量的方法。
- OLS: 最小二乘,让残差平方和最小的回归估计方法。
- t 值: 估计值距离 0 有多少个标准误,用于粗略判断显著性。
- 因子暴露: 股票或组合对某个因子的敏感程度。
- 因子溢价: 承担某个因子暴露后历史平均获得的补偿。
- 异象: 传统模型解释不了但历史数据里反复出现的收益规律。
- 因子动物园: 大量被提出但未必稳健的因子集合。
- 多重检验: 同时测试很多因子导致假阳性概率上升的问题。
- 价值因子: 偏好低估值股票的因子。
- 动量因子: 偏好过去一段时间表现强的股票的因子。
- 质量因子: 偏好盈利稳健、财务质量较高公司的因子。
- 低波动因子: 偏好历史波动较低股票的因子。
- 流动性因子: 描述股票交易难易程度或流动性补偿的因子。
- 信息比率: 策略相对基准的超额收益除以超额收益波动。
