# 03 如何阅读研究报告

报告目录里有多个文件。新手先看这几个:

## html_report.html

浏览器打开。它汇总核心指标和风险提示。

## dashboard.html

用下面的命令从同一目录生成一份可离线分享的自包含仪表盘：

```powershell
uv run python examples/build_report_dashboard.py --report-dir results\research\<时间戳> --open
```

它把净值/回撤、RankIC、换手、拒单原因和最近持仓放在同一页，图表使用内联 SVG，
不连接外部服务。`summary.json` 之外的文件缺失时会显示不可用；未知门状态按
`BLOCK` 处理。指标的直觉、计算口径和判断方法见
[可视化与指标理论手册](可视化与指标理论手册.md)。

## summary.json

机器可读的指标文件。重点字段:

- `total_return`: 总收益
- `annualized_return`: 年化收益
- `annualized_volatility`: 年化波动
- `sharpe_ratio`: 夏普比率
- `max_drawdown`: 最大回撤
- `win_rate`: 完整买卖的胜率

## equity.csv

每日净值。可以用 Excel 打开。

## positions.csv

每日持仓快照。你可以看到每天持有哪些股票、数量、市值、权重。

## orders.csv

订单记录。`status` 是 `filled` 表示成交,`rejected` 表示拒单。`reason` 会告诉你原因,例如现金不足或不可交易。

## trades.csv

成交明细。它记录成交价格、数量、手续费、印花税。

## factor_ic.csv

RankIC 用来粗略观察因子分数和下一期收益的相关性。它不是赚钱保证,只是研究信号质量的一个工具。

## drawdown.png

上半部分是净值曲线,下半部分是回撤。新手一定要看回撤,不要只看收益。
