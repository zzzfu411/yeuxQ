# 04 修改参数与常见错误

配置文件是 `config/research.yaml`。

## 修改持仓数量

```yaml
strategy:
  n_holdings: 30
```

数字越大,组合越分散;数字越小,单只股票影响越大。

## 修改单票上限

```yaml
strategy:
  max_weight: 0.05
```

`0.05` 表示单只股票最多 5% 权重。

## 修改调仓区间

```yaml
research:
  start: "2020-01-01"
  end: "2021-12-31"
```

真实研究时,区间越长越能观察不同市场环境。

## 关闭 demo 数据

```yaml
research:
  allow_demo_data: false
```

关闭后,如果本地没有真实缓存数据,系统会报错。

## 常见错误

### uv 缓存权限失败

可以改用本地虚拟环境:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/ -q --basetemp .\tmp\pytest -p no:cacheprovider
```

### 没有数据

先允许 demo 数据跑通流程,再导入真实数据。

### 报告收益很好

先怀疑过拟合、样本太短、交易成本低估、未来函数。不要直接用于实盘。
