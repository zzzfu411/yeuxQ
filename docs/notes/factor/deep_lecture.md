# 因子投资深度讲义

## 这份讲义怎么用

这是一份原创课程讲义,目标是让你不用一开始啃完因子投资书,也能建立完整因子研究框架。它覆盖因子定义、资产定价公式、常见因子、检验方法、多因子组合、A 股实践陷阱和项目落地。

> 风险提示: 因子历史有效不代表未来有效。因子收益会衰减、拥挤、失效,也可能只是数据挖掘结果。本讲义不是投资建议。

## 0. 因子投资到底在做什么

因子投资研究的是:

```text
为什么不同股票长期平均收益不同?
```

一个股票未来收益受很多东西影响:

- 市场整体涨跌。
- 所属行业。
- 市值大小。
- 估值高低。
- 盈利质量。
- 近期趋势。
- 波动和流动性。
- 随机事件。

因子就是把这些共同特征变成可计算变量。

## 1. 核心公式

资产定价简式:

```text
E[R_i^e] = alpha_i + beta_i' lambda
```

解释:

- `R_i^e`: 股票 `i` 的超额收益。
- `alpha_i`: 已知因子解释不了的部分。
- `beta_i`: 股票对因子的暴露。
- `lambda`: 因子风险溢价。

若 `alpha_i=0`,说明收益完全由因子暴露解释。若策略回归后仍有正 alpha,它可能有独立选股能力。但这里有三个“可能”:

1. 可能是样本内偶然。
2. 可能是遗漏了某个风险因子。
3. 可能交易成本后消失。

## 2. 风险补偿 vs 错误定价

因子有效通常有两类解释。

风险补偿:

```text
某类股票更痛苦、更危险、更难持有,所以长期给更高回报。
```

错误定价:

```text
投资者系统性犯错,导致某些股票被低估或高估。
```

例子:

- 价值因子: 便宜股票可能承担基本面风险,也可能被投资者过度悲观。
- 动量因子: 可能来自信息扩散缓慢,也可能来自投资者追涨。
- 低波动因子: 可能来自投资者偏好高波动“彩票股”。

一个好因子最好能讲出经济逻辑,而不是只有一条漂亮曲线。

## 3. 因子研究标准流程

严肃流程:

```text
提出逻辑
  -> 定义因子
  -> 清洗数据
  -> 构建股票池
  -> 截面标准化
  -> 分组回测
  -> 计算 IC/RankIC
  -> 加入交易成本
  -> 样本外验证
  -> 分析风险暴露
  -> 写研究结论
```

每一步都能造假,所以每一步都要可复现。

## 4. IC 和 RankIC

IC:

```text
IC_t = Corr(f_{i,t}, R_{i,t+1})
```

RankIC:

```text
RankIC_t = Corr(rank(f_{i,t}), rank(R_{i,t+1}))
```

人话解释:

```text
今天因子给股票排的名次,和下期真实收益排名有多一致?
```

如果 RankIC 长期为正,说明高分股票未来更倾向于收益更高。

IC 均值 t 值:

```text
t = mean(IC_t) / (std(IC_t) / sqrt(T))
```

推导来自样本均值标准误:

```text
SE(mean) = std / sqrt(T)
```

注意: 如果 IC 序列有自相关,这个标准误会低估不确定性。

## 5. 分组回测

分组回测是最直观的检验。

步骤:

1. 每个调仓日按因子排序。
2. 分成 5 组或 10 组。
3. 下一期持有各组。
4. 观察高分组是否稳定跑赢低分组。

理想因子应该有单调性:

```text
第5组收益 > 第4组 > 第3组 > 第2组 > 第1组
```

如果只有最高组特别好,中间乱跳,可能不稳。

## 6. 标准化与去极值

因子原始值尺度不同。标准化:

```text
z_i = (x_i - mean(x)) / std(x)
```

去极值常用分位数裁剪:

```text
x_i = min(max(x_i, q_low), q_high)
```

为什么需要?

- PE、成交额、市值有极端值。
- 极端值会支配均值和标准差。
- 多因子合成前必须统一尺度。

项目里 `FactorPipeline` 做了截面 winsorize 和 z-score。

## 7. 价值因子

核心:

```text
买便宜。
```

常见定义:

```text
EP = Earnings / MarketCap = 1 / PE
BP = BookEquity / MarketCap = 1 / PB
```

为什么用倒数? 因为方向更自然: EP 越高越便宜。

风险:

- 负盈利不能直接取倒数。
- 周期行业低 PE 可能是盈利高点。
- 便宜可能是价值陷阱。

项目:

```text
ValueFactor = 1 / pe_ttm
```

## 8. 规模因子

规模:

```text
Size = log(MarketCap)
```

取对数是因为市值分布极端偏斜。小市值可能有更高收益,但也有:

- 流动性差。
- 容量小。
- 暴跌风险。
- A 股制度和监管影响。

小资金可研究小市值,但必须把流动性和停牌放进约束。

## 9. 动量与反转

动量:

```text
MOM = P_t / P_{t-L} - 1
```

12-1 动量:

```text
MOM = P_{t-21} / P_{t-252} - 1
```

跳过最近一个月是因为短期反转可能污染中期趋势。

反转:

```text
REV = - short_term_return
```

A 股中短期反转受 T+1、涨跌停、滑点影响很大。

## 10. 盈利、质量、投资

ROE:

```text
ROE = NetIncome / Equity
```

杜邦:

```text
ROE = 净利率 * 资产周转率 * 权益乘数
```

推导:

```text
(NI/Sales)*(Sales/Assets)*(Assets/Equity)=NI/Equity
```

质量不是单纯 ROE 高。高 ROE 可能来自高杠杆。

投资因子:

```text
AssetGrowth = Assets_t / Assets_{t-1} - 1
```

过度扩张可能压低未来收益。

## 11. 低波动与流动性

波动率:

```text
Vol = std(R_{t-L+1},...,R_t)
```

低波动分数:

```text
Score = -z(Vol)
```

流动性:

```text
Liquidity = log(1 + mean(Amount))
```

A 股实践中,流动性既是因子,更是风控过滤。买不进、卖不出,回测收益就只是纸面数字。

## 12. 多因子组合

简单综合分:

```text
Score_i = sum_k w_k z_{i,k}
```

等权:

```text
w_k = 1/K
```

目标权重:

```text
w_i^* = min(1/N, max_weight)
```

新手先用透明规则,不要一开始用复杂优化。透明规则的好处:

- 容易解释。
- 容易发现错误。
- 不容易过拟合。

## 13. 交易成本和换手

成本后收益:

```text
R_net = R_gross - Cost
```

成本近似:

```text
Cost_t ≈ c * Turnover_t
```

如果月度换手很高,即使毛收益漂亮,净收益也可能被吃掉。

A 股成本包括:

- 佣金。
- 印花税。
- 滑点。
- 涨跌停无法成交。
- T+1。
- 冲击成本。

项目 `PaperBroker` 已经处理一部分。

## 14. 因子动物园和多重检验

如果测试 100 个无效因子,每个因子 5% 概率偶然显著,至少一个假显著的概率:

```text
1 - 0.95^100 ≈ 0.994
```

所以“我发现一个显著因子”并不稀奇。真正重要的是:

- 经济逻辑。
- 样本外。
- 跨市场。
- 交易成本后。
- 风险调整后。
- 不和已有因子重复。

## 15. A 股实践清单

每次做因子研究都检查:

- 是否使用未来数据?
- 是否包含退市和 ST 处理?
- 是否处理停牌?
- 是否考虑涨跌停?
- 是否按 100 股交易?
- 是否有印花税和滑点?
- 是否记录失败实验?
- 是否和基准比较?
- 是否看最大回撤?

## 18. 完整案例: 从“高 ROE 公司更好”到因子研究

假设你的投资直觉是:

```text
盈利能力强的公司更值得买。
```

这句话还不是量化策略,因为它太模糊。需要一步步翻译。

第一步,定义变量:

```text
ROE = NetIncome / BookEquity
```

第二步,定义信息时间:

```text
调仓日只能使用已经公告的财务数据。
```

如果年报在 4 月才披露,就不能拿它去做 1 月选股。这是财务因子最常见的未来函数。

第三步,定义股票池:

```text
全 A 股
剔除 ST
剔除停牌
剔除无价格数据
剔除极低流动性
```

第四步,定义排序:

```text
每月第一个交易日,按 ROE 从高到低排序。
```

第五步,定义组合:

```text
买入前 30 只
等权
单票上限 5%
月度调仓
```

第六步,定义成本:

```text
佣金 + 印花税 + 滑点 + 整百股 + 涨跌停/停牌不可成交
```

第七步,定义评估:

```text
总收益
年化收益
最大回撤
夏普
换手率
RankIC
样本内/样本外
```

第八步,写结论:

```text
ROE 因子在样本内 RankIC 为正,但样本外是否稳定?
收益是否来自质量本身,还是来自行业/市值暴露?
交易成本后是否仍有超额?
最差时期发生在什么时候?
```

这才是完整因子研究。

## 20. Fama-French 思想的直觉

最早的单因子模型类似:

```text
R_i - R_f = alpha_i + beta_i (R_m - R_f) + epsilon_i
```

含义:

- 股票收益超过无风险利率的部分,主要由市场超额收益解释。
- `beta_i` 是市场敏感度。

后来发现市场一个因子解释不了所有横截面收益,于是加入规模和价值:

```text
R_i - R_f = alpha_i + beta_m MKT + beta_s SMB + beta_v HML + epsilon_i
```

其中:

- `SMB`: 小市值减大市值。
- `HML`: 高账面市值比减低账面市值比。

再后来又加入盈利、投资等因子。你不需要一开始背所有模型,但要理解这个演进:

```text
市场因子不够解释
  -> 加规模
  -> 加价值
  -> 加盈利和投资
  -> 检查 alpha 是否还存在
```

这就是因子投资的理论底层: 用更完整的共同风险或共同特征解释收益。

## 21. 为什么多因子不是简单堆料

假设两个因子高度相关:

```text
Corr(value, quality) = 0.9
```

如果你把它们等权相加:

```text
Score = 0.5 z_value + 0.5 z_quality
```

看起来是两个因子,实际可能只是在重复押一个风格。相反,如果两个因子相关较低,组合后可能更稳。

综合分方差:

```text
Var(0.5X + 0.5Y)
= 0.25Var(X) + 0.25Var(Y) + 0.5Cov(X,Y)
```

若 `Var(X)=Var(Y)=1`,则:

```text
Var(Score)=0.5 + 0.5Corr(X,Y)
```

相关越高,分散效果越弱。这就是为什么要看因子相关矩阵。

## 22. A 股数据陷阱清单

做 A 股因子研究,数据问题往往比模型问题更致命。

### 财务数据滞后

错误:

```text
用 2024 年年报数据参与 2024 年 1 月选股。
```

正确:

```text
只有在公告日之后,财务数据才能进入信息集。
```

### 幸存者偏差

错误:

```text
只用现在还上市的股票回测 2015 年以来策略。
```

这样会漏掉退市和长期失败的公司,让历史结果虚高。

### 停牌和涨跌停

错误:

```text
回测显示调仓日能按收盘价买卖,但真实世界股票停牌或一字板。
```

项目里的 `PaperBroker` 会模拟不可买/不可卖的一部分情况。

### 复权问题

价格因子必须使用一致复权口径。前复权适合多数历史收益计算,但分红现金处理仍需谨慎。

### 指数成分变化

如果用今天的中证800成分回测过去,也是未来函数。正确做法是使用历史成分。

## 24. 新手最该避免的 12 个错误

1. 先追求收益,后补风控。
2. 只看年化,不看最大回撤。
3. 忘记交易成本。
4. 忘记财务数据公告日。
5. 用当前成分股回测历史。
6. 不记录失败实验。
7. 为了提高回测不断调参数。
8. 用太短样本判断因子。
9. 因子方向写反。
10. 不处理极端值。
11. 不看因子相关性。
12. 把 demo 数据结果当真实市场结论。
