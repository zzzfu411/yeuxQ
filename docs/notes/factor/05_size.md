# 因子 05: 规模因子

## 这一章解决什么问题

规模因子研究小市值股票是否长期有更高收益,以及这种收益是否来自风险补偿、流动性不足或市场错误定价。

## 先用人话理解

小公司像小船,转向快但抗风浪差;大公司像大船,稳定但弹性小。小市值可能涨得快,也可能跌得狠,还可能买卖不方便。

## 核心概念

- 总市值。
- 流通市值。
- 小市值溢价。
- 容量。
- 流动性约束。

## 数学公式与推导

常用规模变量:

```text
Size_i = log(MarketCap_i)
```

为什么取对数? 市值分布极端右偏。一个万亿市值公司和一个百亿市值公司的差距是 100 倍,直接使用市值会让极端大公司主导统计。对数压缩尺度:

```text
log(10000) - log(100) = log(100)
```

排序时若想偏小市值:

```text
Score_i = -z(log(MarketCap_i))
```

## 放到 A 股量化里怎么用

A 股小市值因子历史上很受关注,但实盘风险很大:

- 流动性不足。
- 监管和壳价值变化。
- 暴露过度集中。
- 大资金容量有限。

## 常见误区

- 小市值收益都能真实成交。
- 忽略停牌和涨跌停。
- 策略收益其实只是小市值暴露。

## 本章练习

用 `market_cap` 设计一个规模过滤: 剔除最小 20% 和最大 10%,观察组合更稳还是收益降低。
