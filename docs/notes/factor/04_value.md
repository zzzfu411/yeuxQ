# 因子 04: 价值因子

## 这一章解决什么问题

价值因子研究“便宜股票是否更值得买”。它是最经典的因子之一,也是最容易被误解的因子之一。

## 先用人话理解

买东西时同样质量当然想买便宜的。但股票里“便宜”可能有两种含义: 一种是被市场低估,另一种是公司真的差,所以便宜。价值因子难点就在区分便宜货和坏货。

## 核心概念

- PE: 市值/净利润。
- PB: 市值/净资产。
- EP: 净利润/市值,即 `1/PE`。
- BP: 净资产/市值,即 `1/PB`。
- 价值陷阱: 看似便宜但基本面持续恶化。

## 数学公式与推导

以 EP 为例:

```text
EP_i = Earnings_i / MarketCap_i = 1 / PE_i
```

如果两个公司利润相同,市值更低的公司 EP 更高。使用 EP 而不是 PE 的一个好处是方向更直观: EP 越高越便宜。

简单价值组合:

```text
Score_i = z(EP_i)
```

若 PE 为负,说明盈利为负,此时 `1/PE` 经济含义很差,通常应设为缺失或单独处理。

## 放到 A 股量化里怎么用

A 股价值因子要特别注意:

- 财报披露滞后。
- 周期行业低 PE 可能是盈利高点。
- 金融和非金融估值口径不同。
- 小市值和低估值可能混在一起。

## 常见误区

- 低 PE 一定好。
- 负 PE 直接取倒数。
- 不考虑行业差异。

## 本章练习

设计一个“便宜且质量不差”的因子: EP 排名前 30%,同时 ROE 大于全市场中位数。
