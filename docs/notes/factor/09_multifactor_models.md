# 因子 09: 多因子模型

## 这一章解决什么问题

本章解释如何把多个因子组合成策略。单因子会失效,多因子试图通过互补信息提高稳健性。

## 先用人话理解

选人不能只看一项指标。只看跑得快可能忽略稳定性,只看稳定可能缺少爆发力。多因子就是多维度面试股票。

## 核心概念

- 因子标准化。
- 因子合成。
- 因子相关性。
- 风格暴露。
- 目标权重。
- 组合约束。

## 数学公式与推导

综合分:

```text
Score_i = sum_{k=1}^K w_k z_{i,k}
```

其中 `sum_k w_k = 1`。若等权:

```text
w_k = 1/K
```

因子相关性矩阵:

```text
C_{ab} = Corr(z_a, z_b)
```

若两个因子高度相关,简单相加不会提供两份独立信息,反而会让某类风格被重复加权。

组合目标权重:

```text
w_i^* = min(1/N, max_weight)
```

本项目第一版采用简单等权和单票上限,透明且容易解释。

## 放到 A 股量化里怎么用

建议先用透明规则:

```text
过滤股票池 -> 因子标准化 -> 综合分 -> 选前 N -> 等权 -> 月度调仓
```

再逐步升级行业中性、市值中性和组合优化。

## 常见误区

- 因子方向没统一。
- 高相关因子重复加权。
- 为了回测收益调太多权重。

## 本章练习

计算价值、质量、动量三个因子分数的相关矩阵,判断是否高度重复。
