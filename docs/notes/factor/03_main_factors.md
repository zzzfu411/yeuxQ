# 因子 03: 主流因子总览

## 这一章解决什么问题

本章建立主流因子的地图: 价值、规模、动量、反转、盈利、投资、质量、低波动和流动性。你先知道每类因子解决什么问题,再逐个深入。

## 先用人话理解

选股像招聘。价值因子看“薪资要求是否便宜”,质量因子看“能力和稳定性”,动量因子看“近期状态”,流动性看“是否容易安排入职和离职”。单看一项容易偏,多项合起来更稳。

## 核心概念

- 价值: 买便宜。
- 规模: 小市值溢价或规模暴露。
- 动量: 强者可能继续强。
- 反转: 短期过度反应可能回归。
- 盈利/质量: 买好公司。
- 投资: 避免过度扩张。
- 低波动: 防御型股票可能有更好风险调整收益。
- 流动性: 可交易性和流动性溢价。

## 数学公式与推导

综合分的简单形式:

```text
Score_i = (1/K) sum_{k=1}^K z_{i,k}
```

其中 `z_{i,k}` 是股票 `i` 在因子 `k` 上标准化后的分数:

```text
z_{i,k} = (x_{i,k} - mean(x_k)) / std(x_k)
```

为什么要标准化? 因子单位不同。PE 可能是 10 到 100,ROE 可能是 0 到 0.3,成交额可能是上亿。不标准化就相当于让单位大的因子支配综合分。

## 放到 A 股量化里怎么用

A 股第一版不宜追求复杂优化。透明方法是: 过滤股票池,计算多类因子,截面标准化,综合排序,月度等权持有。

## 常见误区

- 把所有因子简单相加但方向弄反。
- 忽略因子高度相关。
- 忽略数据披露滞后。
