# 因子 01: 因子投资基础

## 这一章解决什么问题

本章解释什么是因子、什么是 alpha、beta 和风险溢价,以及为什么量化选股常常从“股票特征”开始。

## 先用人话理解

如果一个班级里学生成绩不同,你会问: 是学习时间、基础能力、考试状态还是运气造成的? 因子投资做的事类似: 股票收益不同,可能由估值、动量、质量、规模、波动等共同特征解释。

## 核心概念

- 因子: 能解释或预测收益差异的共同变量。
- alpha: 已知因子解释不了的超额收益。
- beta: 对某个因子的暴露程度。
- 风险溢价: 承担某类风险后获得的平均补偿。
- 异象: 传统模型解释不了但历史上反复出现的收益规律。

## 数学公式与推导

资产定价的简化表达:

```text
E[R_i^e] = alpha_i + beta_i' lambda
```

符号解释:

- `R_i^e`: 第 `i` 只股票的超额收益。
- `alpha_i`: 不能被因子解释的部分。
- `beta_i`: 股票对各因子的暴露向量。
- `lambda`: 各因子的风险溢价向量。

若只有一个市场因子:

```text
E[R_i^e] = alpha_i + beta_i lambda_m
```

如果 `alpha_i = 0`,股票的预期超额收益完全由市场暴露解释。若某策略回归后 alpha 仍显著为正,才可能说明它有独立选股能力。但显著不等于可交易,还要看成本、换手和样本外。

## 放到 A 股量化里怎么用

A 股多因子系统会先定义一批股票特征,如估值、动量、质量、低波动、流动性,再用这些特征给股票打分。关键不是找一个神奇因子,而是建立可验证流程。

## 常见误区

- 把因子当稳赚公式。
- 只看高收益,不看风险暴露。
- 没有经济逻辑就挖因子。
