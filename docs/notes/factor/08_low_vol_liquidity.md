# 因子 08: 低波动与流动性因子

## 这一章解决什么问题

低波动因子研究低风险股票为什么可能有更好风险调整收益。流动性因子研究交易难易程度如何影响收益和执行。

## 先用人话理解

高波动股票像刺激项目,看起来回报诱人,但很多人愿意为刺激付高价,导致未来收益反而不高。流动性像门的宽度,门太窄时你想出去也挤不出去。

## 核心概念

- 波动率。
- Beta。
- 低波动异象。
- 成交额。
- 换手率。
- 流动性溢价。
- 冲击成本。

## 数学公式与推导

历史波动率:

```text
Vol_i = std(R_{i,t-L+1}, ..., R_{i,t})
```

低波动分数:

```text
Score_i = -z(Vol_i)
```

成交额流动性:

```text
Liquidity_i = log(1 + mean(Amount_i))
```

为什么用 `log(1+x)`? 成交额分布极端偏斜,对数能压缩极端值;加 1 避免 0 成交额取对数问题。

## 放到 A 股量化里怎么用

低波动适合降低组合回撤。流动性在 A 股更像风控条件: 即使低流动性有溢价,也可能无法以回测价格成交。

## 常见误区

- 低波动永远安全。
- 流动性越低收益越高,所以越低越好。
- 忽略大资金容量。
