# FPP 03: 预测工具箱

## 这一章解决什么问题

本章给出预测工作流的基本工具: 简单基准、数据变换、残差诊断、误差度量和预测区间。对量化来说,它告诉你不要被复杂模型迷住,先打败朴素基准。

## 先用人话理解

做预测像参加比赛。你不能只说自己跑得快,还要和基准比。量化策略也不能只说年化不错,还要和指数、等权组合、买入持有这些“朴素选手”比。

## 核心概念

- 朴素预测: 下一期等于上一期。
- 漂移法: 用历史平均斜率外推。
- 残差: 真实值减预测值。
- MAE/RMSE/MAPE: 常见误差指标。
- 预测区间: 未来值可能落入的范围。

## 数学公式与推导

残差:

```text
e_t = y_t - hat_y_t
```

RMSE:

```text
RMSE = sqrt((1/n) sum_t e_t^2)
```

为什么平方误差会重罚大错? 若误差从 1 变成 2,平方从 1 变成 4;若误差从 1 变成 10,平方从 1 变成 100。金融中大亏尤其重要,所以这类惩罚很有意义。

样本均值是常数预测下 MSE 最优值。设预测常数为 `a`:

```text
S(a) = sum_t (y_t - a)^2
```

求导:

```text
dS/da = -2 sum_t (y_t - a)
```

令导数为 0:

```text
sum_t y_t - n a = 0
a = y_bar
```

所以如果你只能报一个常数预测,历史均值是平方误差下的最优选择。

## 常见误区

- 只看收益,不看基准。
- 只看样本内表现。
- 残差还有明显规律却不继续诊断。
