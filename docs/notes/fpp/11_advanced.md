# FPP 11: 高级预测方法

## 这一章解决什么问题

本章介绍更复杂的预测方法,如复杂季节性、VAR、神经网络、Bootstrap、Bagging 和组合预测。它帮助你知道工具箱里还有什么,但不鼓励新手一开始就堆模型。

## 先用人话理解

高级模型像高级厨具。厨具再贵,食材坏了也做不好菜。量化里食材就是数据质量、问题定义和样本外验证。

## 核心概念

- VAR: 多变量时间序列互相影响。
- 神经网络: 非线性函数逼近。
- Bootstrap: 从样本中重复抽样估计不确定性。
- Bagging: 多模型平均降低方差。
- 组合预测: 不押注单一模型。

## 数学公式与推导

模型平均:

```text
hat_y_c = (1/M) sum_{m=1}^M hat_y_m
```

若每个模型误差 `e_m` 方差相同为 `sigma^2`,两两相关为 `rho`,平均误差方差:

```text
Var(e_c) = sigma^2 [rho + (1-rho)/M]
```

推导:

```text
Var((1/M)sum e_m)
= (1/M^2)[sum Var(e_m) + 2 sum_{i<j} Cov(e_i,e_j)]
= (1/M^2)[M sigma^2 + M(M-1) rho sigma^2]
= sigma^2[1/M + (M-1)rho/M]
= sigma^2[rho + (1-rho)/M]
```

当模型误差相关性低时,组合能显著降低方差。这是多模型和多因子组合的核心直觉。

## 放到 A 股量化里怎么用

- 不要只用一个因子押注。
- 多因子能分散因子失效风险。
- 机器学习只有在数据质量、标签定义和验证严格时才有意义。

## 常见误区

- 模型越复杂越好。
- 训练集越拟合越好。
- 不理解数据泄漏就上机器学习。
