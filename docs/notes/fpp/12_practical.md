# FPP 12: 实际预测问题

## 这一章解决什么问题

本章讨论真实预测中的脏问题: 训练/测试切分、异常值、缺失值、短序列、模型选择和持续更新。它是从教材走向实战的桥。

## 先用人话理解

真实数据像厨房里的食材,可能过期、缺斤少两、标签贴错。模型再聪明,吃到坏数据也会出坏结果。量化里数据清洗和验证比炫技更重要。

## 核心概念

- 训练集/验证集/测试集。
- 缺失值。
- 离群值。
- 结构突变。
- 滚动验证。
- 预测组合。

## 数学公式与推导

样本外误差:

```text
TestError = (1/N_test) sum_{t in test} L(y_t, hat_y_t)
```

其中 `L` 是损失函数,如平方误差或绝对误差。关键是 `hat_y_t` 必须只用 `t` 之前可得信息生成。

滚动预测框架:

```text
for t in test_dates:
    fit model using data <= t-1
    predict y_t
    record loss
```

这和量化回测的防未来函数是一回事。

最大的数据泄漏形式:

```text
用全样本标准化 -> 再切训练测试
```

正确方式:

```text
每个调仓日只用当时截面或历史可得数据标准化
```

## 常见误区

- 用清洗后的全样本股票池回测,产生幸存者偏差。
- 只看最优参数,不看参数稳定性。
- 交易成本假设过低。
