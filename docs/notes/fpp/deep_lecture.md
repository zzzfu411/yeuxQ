# 《预测: 方法与实践》深度讲义

## 这份讲义怎么用

这不是原书复刻,而是一份面向量化初学者的原创课程讲义。目标是让你先建立预测学的完整骨架: 什么能预测、如何看时间序列、如何建模型、如何评估误差、如何避免样本外翻车。读完后再回到逐章笔记,你会更知道每章在系统里的位置。

> 风险提示: 预测模型和历史回测都不能保证未来收益。金融市场的噪声、制度变化和交易成本会让许多历史规律失效。

## 0. 全书主线

预测问题可以浓缩成一句话:

```text
站在时间 t,只用当时已知的信息 I_t,估计未来 Y_{t+h}。
```

数学表达:

```text
hat_y_{t+h|t} = f(I_t)
```

若损失函数是均方误差,最优预测是条件期望:

```text
hat_y_{t+h|t} = E[Y_{t+h} | I_t]
```

这条主线贯穿全书。所有模型,不管是朴素预测、回归、指数平滑、ARIMA、动态回归还是高级模型,本质上都在回答:

1. 信息集 `I_t` 里有什么?
2. 预测函数 `f` 怎么选?
3. 预测误差怎么度量?
4. 样本外是否仍然有效?

在量化交易里,这四个问题分别变成:

1. 我在调仓日到底知道哪些数据?
2. 因子或模型如何把数据转成信号?
3. 信号带来的收益是否超过成本?
4. 换市场环境后是否还能活?

## 1. 可预测性: 不是所有东西都值得预测

预测是否容易,取决于三个条件:

- 信号强: 历史中确实有稳定规律。
- 噪声小: 随机扰动没有完全淹没规律。
- 结构稳: 未来机制和过去相似。

天气比股票好预测,不是因为气象学更神秘,而是天气服从明确物理规律,观测数据也丰富。股票价格则受到投资者行为、政策、流动性、突发事件和反馈交易影响。很多时候,价格本身接近随机游走。

随机游走:

```text
P_t = P_{t-1} + epsilon_t
```

如果 `epsilon_t` 是不可预测冲击,那么最好的价格预测常常只是:

```text
hat_P_{t+1|t} = P_t
```

这就是朴素预测在很多金融价格上很难被击败的原因。

### 对小白的直觉

如果一个人每一步都是闭着眼随机走,你可以预测他“下一步后的位置大概在现在附近”,但很难预测他具体往左还是往右。股价短期方向常常就像这样。

### 项目实验

在 `src/quantify/research/factors.py` 中看 `MomentumFactor`: 它没有预测明天价格,而是用历史收益给股票排序。多因子选股更关注“股票之间谁更好”,而不是“明天指数几点”。

## 2. 图形分析: 建模前先让数据说话

时间序列图形至少看四件事:

1. 趋势: 长期上升或下降。
2. 季节性: 固定周期重复。
3. 异常值: 突然跳变。
4. 自相关: 今天和过去是否有关。

自相关公式:

```text
r_k =
sum_{t=k+1}^T (y_t - y_bar)(y_{t-k} - y_bar)
/
sum_{t=1}^T (y_t - y_bar)^2
```

分子衡量当前值和滞后值是否一起偏离均值。分母把尺度标准化。

白噪声满足:

```text
E[epsilon_t] = 0
Var(epsilon_t) = sigma^2
Cov(epsilon_t, epsilon_{t-k}) = 0
```

白噪声像没有记忆的硬币。前面连续 5 次正面,并不会让下一次更可能反面。

### 量化里的用法

策略净值图告诉你赚钱路径;回撤图告诉你最难熬的时刻。一个策略如果最终收益不错,但中间腰斩过,对多数人并不可执行。

项目里:

- `results/research/<timestamp>/equity.csv`: 每日净值。
- `results/research/<timestamp>/drawdown.png`: 净值与回撤图。

## 3. 基准模型: 简单方法是照妖镜

预测工具箱里最重要的不是复杂模型,而是基准。

常见基准:

- 均值预测: 未来等于历史平均。
- 朴素预测: 未来等于当前。
- 季节朴素: 未来等于上一周期同位置。
- 漂移法: 用历史平均斜率外推。

### 为什么样本均值是 MSE 最优常数预测

令常数预测为 `a`,最小化:

```text
S(a) = sum_t (y_t - a)^2
```

求导:

```text
dS/da = -2 sum_t (y_t - a)
```

令导数为 0:

```text
sum_t y_t - n a = 0
a = y_bar
```

所以如果你只能报一个固定数字,历史均值是平方误差意义下最优的。

### 量化里的基准

策略必须回答:

```text
我是否跑赢了指数?
我是否跑赢了等权股票池?
我是否只是承担了更高风险?
交易成本后是否仍然有效?
```

没有基准的回测没有解释力。

## 4. 残差: 模型没解释完的尾巴

残差:

```text
e_t = y_t - hat_y_t
```

一个好模型的残差应该像白噪声。如果残差还有趋势、自相关或季节性,说明模型漏掉了信息。

常见误差:

```text
MAE = mean(|e_t|)
RMSE = sqrt(mean(e_t^2))
MAPE = mean(|e_t / y_t|)
```

RMSE 重罚大错。金融里大错通常更危险,因为一次大亏可能让策略无法继续。

## 5. 判断预测: 人的经验要被制度化

人的判断可以提供信息,但也容易有偏差:

- 近期偏差: 最近发生的事被过度重视。
- 确认偏误: 只找支持自己观点的数据。
- 过度自信: 低估不确定性。

量化的做法不是不要经验,而是把经验变成可验证规则。

例子:

```text
经验: 高 ROE 公司更好。
规则: 每月按 ROE 截面排序,买前 30 只,加入 ST/停牌过滤和交易成本。
验证: 看样本外 RankIC、回撤、换手。
```

## 6. 回归: 用变量解释未来

线性模型:

```text
y = X beta + epsilon
```

最小二乘:

```text
min_beta (y - X beta)'(y - X beta)
```

展开并求导:

```text
S = y'y - 2 beta'X'y + beta'X'X beta
dS/dbeta = -2X'y + 2X'X beta
```

令导数为 0:

```text
X'X beta = X'y
beta_hat = (X'X)^(-1)X'y
```

### 量化解释

未来收益可以写成:

```text
R_i = alpha + beta_1 value_i + beta_2 momentum_i + beta_3 quality_i + epsilon_i
```

但回归只说明统计关系。它不自动证明因果,也不保证交易后赚钱。

## 7. 分解: 趋势、季节、噪声

加法分解:

```text
Y_t = T_t + S_t + R_t
```

乘法分解:

```text
Y_t = T_t * S_t * R_t
```

取对数后:

```text
log Y_t = log T_t + log S_t + log R_t
```

量化复盘也要分解:

```text
组合收益 = 市场贡献 + 行业贡献 + 风格贡献 + 个股选择 + 交易成本 + 现金拖累
```

如果不分解,你可能把牛市上涨误认为策略能力。

## 8. 指数平滑: 越近越重要

简单指数平滑:

```text
l_t = alpha y_t + (1-alpha)l_{t-1}
```

递归展开:

```text
l_t = alpha y_t
    + alpha(1-alpha)y_{t-1}
    + alpha(1-alpha)^2 y_{t-2}
    + ...
```

旧数据权重按指数衰减。

量化里:

- EMA。
- 指数加权波动率。
- 成交额平滑。
- 趋势跟踪。

## 9. ARIMA: 价格像位置,收益像脚步

随机游走:

```text
Y_t = Y_{t-1} + epsilon_t
```

展开:

```text
Y_t = Y_0 + sum_{i=1}^t epsilon_i
```

若 `Var(epsilon_i)=sigma^2`:

```text
Var(Y_t)=t sigma^2
```

方差随时间增加,所以不平稳。

差分:

```text
Delta Y_t = Y_t - Y_{t-1} = epsilon_t
```

这解释了为什么金融建模更常看收益率而不是价格。

ARIMA:

```text
Phi(B)(1-B)^dY_t = Theta(B)epsilon_t
```

其中 `B` 是滞后算子。

## 10. 动态回归: 外部变量 + 时间结构

普通回归:

```text
Y_t = beta_0 + beta X_t + epsilon_t
```

动态回归允许误差有时间结构:

```text
Phi(B)(1-B)^d epsilon_t = Theta(B)a_t
```

量化里可用于:

- 组合收益对市场/行业/风格因子的归因。
- 指数收益对估值、利率、成交额的解释。
- 波动率对历史波动和成交量的解释。

## 11. 分层预测: 总量和部分要对得上

层级关系:

```text
y_t = S b_t
```

其中 `b_t` 是底层序列,`S` 是加总矩阵。

量化里:

```text
总组合收益 = 各股票收益按权重加总
行业收益 = 行业内股票收益按权重加总
```

如果组合总收益和持仓贡献对不上,说明数据或记账出了问题。

## 12. 高级模型: 复杂不是免费午餐

模型平均误差方差:

```text
Var(e_c) = sigma^2 [rho + (1-rho)/M]
```

含义:

- `M`: 模型数量。
- `rho`: 模型误差相关性。
- 若误差相关低,组合模型能降低方差。
- 若模型都犯同样错误,平均也救不了。

这就是多因子组合的数学直觉。

## 13. 实战预测问题

真实量化中最重要的问题:

- 缺失值。
- 异常值。
- 数据修订。
- 样本外。
- 未来函数。
- 交易成本。
- 结构变化。

滚动预测框架:

```text
for t in test_dates:
    fit model using data <= t-1
    predict y_t
    record error
```

这和回测完全一致: 每一步只能用当时可得信息。

## 14. 你应该带走的能力

读完这条主线,你应该能做到:

1. 把预测问题写成 `E[Y未来 | 当前信息]`。
2. 先画图,再建模。
3. 为任何模型设置朴素基准。
4. 用残差诊断模型是否漏信息。
5. 区分价格和收益率。
6. 知道复杂模型为何容易过拟合。
7. 在量化回测里坚决防未来函数。

## 15. 一个完整工作案例: 预测策略净值风险

假设你已经运行了:

```powershell
uv run python examples/run_research.py --config config/research.yaml
```

你会得到 `equity.csv`。现在我们用预测学的方式分析它。

第一步,定义问题:

```text
目标变量: 下一期组合收益 R_{t+1}
信息集: 当前和过去的净值、收益、回撤、成交、因子分数
预测周期: 1 天或 1 个月
损失函数: 大亏比小误差更重要,所以不能只看 MSE
```

第二步,从净值变收益:

```text
R_t = Equity_t / Equity_{t-1} - 1
```

为什么不直接预测净值? 因为净值通常有趋势,不平稳;收益率更接近平稳。

第三步,建立基准:

```text
hat_R_{t+1} = mean(R_1, ..., R_t)
```

这是均值预测。任何复杂模型都要先问: 是否真的比它好?

第四步,检查残差:

```text
e_{t+1} = R_{t+1} - hat_R_{t+1}
```

如果残差在大跌日集中变负,说明模型没有识别风险状态。如果残差有自相关,说明还有时间结构可挖。

第五步,加入外部变量:

```text
R_{t+1} = alpha + beta_1 Drawdown_t + beta_2 Turnover_t + beta_3 RankIC_t + epsilon_{t+1}
```

解释:

- `Drawdown_t`: 当前回撤状态,可能代表风险环境。
- `Turnover_t`: 换手高时成本和噪声可能更大。
- `RankIC_t`: 因子近期质量。

第六步,样本外验证。不能用全样本拟合后再宣布成功,而要滚动:

```text
for each month:
    use previous data to estimate relationship
    predict next month
    record prediction error
```

第七步,把预测转成行动。预测收益略高并不一定值得加仓,还要考虑:

- 不确定性区间。
- 最大回撤。
- 交易成本。
- 当前持仓是否拥挤。
- 预测错误时的损失。

这就是预测学在量化中的实际用法: 它不是让你“算准明天涨跌”,而是让你建立一套诚实评估不确定性的流程。

## 16. 公式速查表

条件期望:

```text
hat_y = E[Y | I]
```

残差:

```text
e_t = y_t - hat_y_t
```

RMSE:

```text
sqrt(mean(e_t^2))
```

一阶差分:

```text
Delta Y_t = Y_t - Y_{t-1}
```

收益率:

```text
R_t = P_t / P_{t-1} - 1
```

AR(1):

```text
Y_t = phi Y_{t-1} + epsilon_t
```

指数平滑:

```text
l_t = alpha y_t + (1-alpha)l_{t-1}
```

组合预测:

```text
hat_y_c = sum_m w_m hat_y_m
```

最大回撤:

```text
DD_t = 1 - Equity_t / max_{s<=t} Equity_s
```

这些公式看起来分散,但都服务同一件事: 用过去和当前信息,对未来做可检验的估计。

## 17. 章节路线和学习重点

如果你时间有限,按下面顺序读:

1. 入门: 建立预测问题意识。
2. 图形: 先看数据形状。
3. 工具箱: 建立基准和误差评估。
4. 回归: 学会解释变量和残差。
5. 分解: 区分趋势、季节和噪声。
6. ARIMA: 理解平稳性和差分。
7. 实际问题: 学会防数据泄漏。

暂时可以后置:

- 高级预测方法。
- 分层预测。
- 复杂季节性。

量化初学者最容易犯的错不是不会神经网络,而是:

```text
没有基准
没有样本外
没有交易成本
没有防未来函数
没有看回撤
```
