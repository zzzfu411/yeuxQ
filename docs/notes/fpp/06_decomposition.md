# FPP 06: 时间序列分解

## 这一章解决什么问题

本章把时间序列拆成趋势、季节性、周期和随机项。它帮助我们区分“长期方向”“规律性波动”和“噪声”。

## 先用人话理解

一家奶茶店销量每天变化,可能有长期增长趋势、夏天更热卖的季节性、节假日冲击和随机天气影响。股票组合收益也类似,别把牛市趋势误认为策略能力。

## 核心概念

- 趋势: 长期上升或下降方向。
- 季节性: 固定周期重复出现的模式。
- 周期: 不固定长度的经济或行业波动。
- 残差项: 分解后剩下的随机成分。
- 加法分解与乘法分解。

## 数学公式与推导

加法分解:

```text
Y_t = T_t + S_t + R_t
```

乘法分解:

```text
Y_t = T_t * S_t * R_t
```

若波动幅度随水平增加而增加,常先取对数:

```text
log(Y_t) = log(T_t) + log(S_t) + log(R_t)
```

这把乘法关系转成加法关系。因为:

```text
log(abc) = log(a) + log(b) + log(c)
```

移动平均估计趋势:

```text
T_t = (1/m) sum_{j=0}^{m-1} Y_{t-j}
```

它本质上是低通滤波: 平滑掉高频噪声,保留慢变化趋势。

## 放到 A 股量化里怎么用

- 牛市带来的净值上涨要和选股能力区分。
- 财报季可能带来季节性。
- 行业周期会影响因子表现。
- 策略复盘要拆成市场、行业、风格和个股贡献。

## 常见误区

- 把市场上涨当作策略 alpha。
- 用太短样本判断长期趋势。
- 分解结果依赖方法和窗口,不是唯一真相。
