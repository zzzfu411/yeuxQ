# FPP 09: 动态回归

## 这一章解决什么问题

动态回归把外部解释变量和时间序列误差结构结合起来。它适合目标变量受外部因素影响,同时残差又有时间相关性的场景。

## 先用人话理解

预测销量时,不仅要看过去销量,还要看促销、节假日、天气。预测指数收益时,也不能只看指数自己,还要看估值、利率、成交额、波动率等外部变量。

## 核心概念

- 外生变量: 不由模型内部决定的解释变量。
- 回归误差自相关: 残差不是白噪声。
- ARIMAX: 带外部变量的 ARIMA。
- 滞后变量: 外部变量影响可能延后出现。

## 数学公式与推导

动态回归:

```text
Y_t = beta_0 + beta_1 X_{1,t} + ... + beta_k X_{k,t} + eta_t
```

误差项 `eta_t` 不是白噪声,而服从 ARIMA:

```text
Phi(B)(1-B)^d eta_t = Theta(B) epsilon_t
```

这比普通回归更严格,因为普通回归默认残差没有系统记忆。若残差自相关,OLS 系数可能仍无偏,但标准误通常错误,显著性判断会失真。

## 放到 A 股量化里怎么用

可以研究:

- 指数未来收益与估值、成交额、利率的关系。
- 策略收益与市场、行业、风格因子的关系。
- 波动率与过去波动、成交量的关系。

## 常见误区

- 外生变量其实可能也是被市场共同驱动。
- 用未来才知道的宏观或财务数据。
- 残差自相关却用普通 t 检验。

## 本章练习

把策略月收益和市场月收益放在一起,做一个简单回归,看策略是否主要暴露于市场。
