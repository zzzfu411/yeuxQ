# FPP 10: 分层和分组时间序列

## 这一章解决什么问题

本章处理多层级数据的一致预测问题。总量和子项之间有加总关系,预测时不能互相矛盾。

## 先用人话理解

公司全国销量等于各省销量之和。如果你预测全国卖 100 万件,各省加起来却是 130 万件,这就不一致。组合收益也有类似结构: 总组合收益来自各行业、各股票、现金和成本。

## 核心概念

- 分层结构: 总量、子组、明细项。
- 分组结构: 多个交叉分类。
- 一致性: 底层预测加总后等于上层预测。
- 自上而下、自下而上、中间调和。

## 数学公式与推导

设底层序列向量为 `b_t`,总序列和中间层为 `y_t`,有:

```text
y_t = S b_t
```

其中 `S` 是汇总矩阵。若先独立预测得到 `hat_y`,可能不满足层级一致。调和预测寻找新的 `tilde_y`:

```text
tilde_y = S tilde_b
```

目标是在尽量接近原预测的同时满足加总约束。最小二乘调和可写成加权投影问题。

## 放到 A 股量化里怎么用

- 组合收益 = 股票收益加权和。
- 行业收益 = 行业内股票收益组合。
- 总风险 = 市场风险 + 行业风险 + 个股风险 + 交易成本。

做复盘时应拆解:

```text
总收益 = 行业配置 + 行业内选股 + 风格暴露 + 交易成本 + 现金拖累
```

## 常见误区

- 只看总收益,不知道收益来自哪里。
- 行业集中导致看似 alpha,其实只是押中行业。
- 个股收益和组合收益权重不一致。
