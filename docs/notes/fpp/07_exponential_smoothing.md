# FPP 07: 指数平滑

## 这一章解决什么问题

本章介绍一类简单但强大的预测方法: 给最近数据更高权重,给旧数据更低权重。它是移动平均、趋势跟踪和波动率估计的亲戚。

## 先用人话理解

判断一个人的近期状态,昨天的表现比三年前更有参考价值。指数平滑就是把“越近越重要”写成公式。

## 核心概念

- 平滑参数 `alpha`: 新数据权重。
- 简单指数平滑: 无趋势、无季节。
- Holt 方法: 加入趋势。
- Holt-Winters: 加入趋势和季节性。
- 状态更新: 每来一个新数据就更新估计。

## 数学公式与推导

简单指数平滑:

```text
l_t = alpha y_t + (1-alpha) l_{t-1}
```

其中:

- `l_t`: 当前平滑水平。
- `alpha in (0,1)`: 新观测权重。

递归展开:

```text
l_t = alpha y_t + alpha(1-alpha)y_{t-1} + alpha(1-alpha)^2 y_{t-2} + ...
```

推导: 不断把 `l_{t-1}`, `l_{t-2}` 代入即可。因为 `(1-alpha)^k` 随 `k` 增大而衰减,旧数据权重呈指数下降。

一步预测:

```text
hat_y_{t+1|t} = l_t
```

适用条件:

- 序列水平缓慢变化。
- 趋势或季节性不强时简单平滑更合适。
- 金融价格噪声大,不能把平滑线当必然方向。

## 放到 A 股量化里怎么用

- EMA 均线。
- 波动率指数加权估计。
- 成交额平滑。
- 趋势类择时信号。

## 常见误区

- 均线穿越不等于一定上涨。
- 参数越优化越可能过拟合。
- 平滑会滞后,行情快速反转时容易慢半拍。
