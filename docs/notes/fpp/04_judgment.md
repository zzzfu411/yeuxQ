# FPP 04: 判断预测

## 这一章解决什么问题

本章讨论人的经验和判断如何进入预测。数据模型不是万能的,专家判断也不是万能的。关键是把判断记录、结构化、可复盘。

## 先用人话理解

经验像老司机的路感。它能帮你避开某些坑,但也可能让你过度自信。量化的做法不是消灭经验,而是把经验写成规则,再让数据审判它。

## 核心概念

- 专家判断: 来自经验而非纯模型。
- 偏差: 人类容易受近期事件、确认偏误、过度自信影响。
- 德尔菲法: 聚合多位专家判断。
- 情景分析: 对不同未来路径做条件讨论。
- 预测校准: 检查过去判断是否过度乐观或悲观。

## 数学公式与推导

判断预测常用加权组合:

```text
hat_y = w_m hat_y_model + (1 - w_m) hat_y_judgment
```

其中:

- `hat_y_model`: 模型预测。
- `hat_y_judgment`: 人工判断。
- `w_m`: 模型权重,位于 `[0,1]`。

如果两个预测误差分别为 `e_1`, `e_2`,组合误差:

```text
e_c = w e_1 + (1-w)e_2
```

方差:

```text
Var(e_c) = w^2 Var(e_1) + (1-w)^2 Var(e_2) + 2w(1-w)Cov(e_1,e_2)
```

若两个误差相关性低,组合预测可能降低误差。这也是多因子和多模型组合的数学直觉。

## 放到 A 股量化里怎么用

你可以从经验提出因子:

- “高 ROE 公司更稳健” -> 质量因子。
- “爆炒股风险高” -> 低波动或反转因子。
- “成交太少不容易卖” -> 流动性过滤。

但每条经验必须被回测、样本外和交易成本检验。

## 常见误区

- 用经验绕过数据检验。
- 因为一次成功就相信判断永远正确。
- 只记录结论,不记录当时的信息和理由。
