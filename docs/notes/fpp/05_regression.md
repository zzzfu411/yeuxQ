# FPP 05: 时间序列回归

## 这一章解决什么问题

本章讲如何用一个或多个解释变量预测目标序列。它是宏观预测、因子暴露分析、收益归因的共同基础。

## 先用人话理解

回归像问“成绩由哪些因素解释”。如果未来收益是成绩,估值、动量、质量就是可能的解释变量。回归会告诉你每个变量和成绩的线性关系,但不会自动证明因果。

## 核心概念

- 因变量: 被预测变量。
- 自变量: 用来解释的变量。
- 系数: 自变量变化一个单位时,因变量平均变化多少。
- 残差: 模型没解释掉的部分。
- 多重共线性: 自变量之间高度重复。
- 伪回归: 非平稳序列之间看似显著但没有真实关系。

## 数学公式与推导

线性回归:

```text
y = X beta + epsilon
```

最小二乘估计:

```text
beta_hat = (X'X)^(-1)X'y
```

推导见 [../math/02_ols.md](../math/02_ols.md)。

一元回归斜率可以写成:

```text
beta_hat = Cov(x,y) / Var(x)
```

推导思路: 对模型 `y_i = alpha + beta x_i + e_i` 做最小二乘,两条一阶条件是残差和为 0、残差与 `x` 的乘积和为 0。代入 `alpha_hat = y_bar - beta_hat x_bar`,可得上式。

适用条件:

- 线性近似合理。
- 自变量不能完美共线。
- 用时间序列回归时要检查自相关和非平稳。

## 放到 A 股量化里怎么用

常见写法:

```text
R_i = alpha_i + beta_mkt MKT + beta_value VALUE + beta_mom MOM + epsilon_i
```

如果一个策略收益主要来自市场 beta,它并没有真正选股 alpha。

## 常见误区

- 相关不等于因果。
- 非平稳价格序列直接回归容易出伪回归。
- 变量越多越容易过拟合。

## 本章练习

用一个因子的分数和下一期收益做散点图,观察关系是否线性、是否被极端值驱动。
