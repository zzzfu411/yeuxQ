# FPP 02: 时间序列图形

## 这一章解决什么问题

本章教你在建模前先画图。图形能快速暴露趋势、季节性、异常值、自相关和结构变化,避免一上来就用复杂模型误判数据。

## 先用人话理解

时间序列像人的体检报告。医生不会只看一个数,会看曲线、波动、异常尖峰和长期趋势。量化研究也一样,净值曲线和回撤图往往比一句“年化收益多少”更诚实。

## 核心概念

- 时间图: 横轴时间,纵轴变量。
- 季节图: 对比不同年份同一季节或月份。
- 滞后图: 比较 `Y_t` 和 `Y_{t-k}`。
- ACF: 自相关函数,衡量序列和自身滞后项的相关性。
- 白噪声: 没有可利用记忆的随机序列。

## 数学公式与推导

样本自相关:

```text
r_k = sum_{t=k+1}^T (y_t - y_bar)(y_{t-k} - y_bar) / sum_{t=1}^T (y_t - y_bar)^2
```

符号解释:

- `k`: 滞后阶数。
- `y_bar`: 样本均值。
- 分子: 当前值和滞后值共同偏离均值的程度。
- 分母: 总方差尺度。

若 `r_k` 接近 1,说明当前值和 `k` 期前同向移动明显;若接近 0,说明线性记忆弱。

白噪声定义:

```text
E[epsilon_t] = 0
Var(epsilon_t) = sigma^2
Cov(epsilon_t, epsilon_{t-k}) = 0, k != 0
```

白噪声像“没有记忆的硬币”: 上一次正面不会告诉你下一次是什么。

## 放到 A 股量化里怎么用

- 价格图看趋势,但不能直接证明可预测。
- 收益率图看波动聚集和极端值。
- 净值图看策略是否长期平稳。
- 回撤图看策略最痛苦的时候。
- ACF 可用于检查收益、成交量或波动是否有记忆。

## 常见误区

- 看到上涨趋势就以为能赚钱。
- 只看净值不看回撤。
- 把异常值删掉但不记录原因。
