# FPP 01: 入门

## 这一章解决什么问题

本章回答预测最根本的问题: 什么东西可以预测,预测和目标/计划有什么不同,一个严肃预测流程应该怎样开始。对量化来说,它提醒我们先定义问题,再谈模型。

## 先用人话理解

预测像看天气预报。天气预报不会保证明天下雨,它只是在已有气压、湿度、风向等信息下给出概率判断。量化也是一样: 策略不是承诺明天赚钱,而是说在某些可观测条件下,长期胜率或收益分布可能更有利。

## 核心概念

- 预测对象: 未来要估计的量,如收益率、波动率、成交额。
- 预测周期: 预测未来 1 天、1 周、1 月还是更久。
- 可预测性: 规律稳定、噪声较小、数据足够时更高。
- 预测、目标、计划: 预测是估计未来,目标是希望达到的状态,计划是行动安排。
- 样本外: 研发后没参与调参的数据,用于检验泛化。

## 数学公式与推导

预测问题可以写成条件期望:

```text
hat_y_{t+h|t} = E[Y_{t+h} | I_t]
```

符号解释:

- `Y_{t+h}`: 未来第 `t+h` 期的目标变量。
- `I_t`: 在时间 `t` 已知的信息集。
- `hat_y_{t+h|t}`: 站在 `t` 时刻对未来 `t+h` 的预测。

为什么条件期望是平方误差下的最优预测? 对任意常数预测 `a`,最小化:

```text
E[(Y - a)^2]
```

展开:

```text
E[(Y-a)^2] = E[Y^2] - 2aE[Y] + a^2
```

对 `a` 求导:

```text
d/da = -2E[Y] + 2a
```

令导数为 0:

```text
a = E[Y]
```

若有信息 `I`,同理可得最优预测是 `E[Y|I]`。适用条件是损失函数为均方误差;如果你更怕大亏,损失函数就不一定是平方误差。

## 放到 A 股量化里怎么用

将“我觉得低估值股票会涨”改写为:

```text
在每月调仓日,用当时已知的估值数据对股票排序,买入估值较低且通过流动性/ST/停牌过滤的股票,观察未来一个月组合收益。
```

这个表达明确了预测对象、信息集、预测周期和可检验方式。

## 常见误区

- 把目标当预测: “我要年化 20%”不是预测,只是愿望。
- 把回测好看当可预测: 样本内拟合不等于未来有效。
- 不定义信息集: 如果用了未来财报,回测就是作弊。
