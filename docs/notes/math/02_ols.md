# 数学补充 02: 最小二乘与回归推导

## 这一章解决什么问题

回归是预测和因子检验的共同语言。本章证明为什么最小二乘会得到正规方程,并说明回归系数在量化中的含义。

## 先用人话理解

假设你用一条直线解释一堆散点。每个点到直线的竖直距离叫残差。最小二乘就是找一条线,让所有残差平方和最小。平方的作用是避免正负误差互相抵消,也惩罚特别大的错误。

## 核心概念

- 因变量 `y`: 要解释或预测的量,如未来收益。
- 自变量矩阵 `X`: 解释变量,如价值、动量、质量因子。
- 系数 `beta`: 每个变量的边际影响。
- 残差 `epsilon`: 模型没有解释掉的部分。

## 数学公式与推导

线性模型:

```text
y = X beta + epsilon
```

其中 `y` 是 `n x 1`, `X` 是 `n x k`, `beta` 是 `k x 1`。

最小二乘目标:

```text
min_beta S(beta) = (y - X beta)'(y - X beta)
```

展开:

```text
S(beta)
= y'y - y'X beta - beta'X'y + beta'X'X beta
```

因为 `y'X beta` 是标量,等于它的转置 `beta'X'y`,所以:

```text
S(beta) = y'y - 2 beta'X'y + beta'X'X beta
```

对 `beta` 求导:

```text
dS/dbeta = -2X'y + 2X'X beta
```

令导数为 0:

```text
X'X beta = X'y
```

如果 `X'X` 可逆:

```text
beta_hat = (X'X)^(-1) X'y
```

这就是正规方程。

适用条件:

- `X'X` 必须可逆,自变量不能完全共线。
- 残差若异方差或自相关,普通标准误会失真。
- 回归关系是线性近似,不是因果证明。

## 放到 A 股量化里怎么用

因子暴露回归:

```text
R_i = alpha_i + beta_value VALUE_i + beta_mom MOM_i + epsilon_i
```

如果 `beta_value` 显著为正,说明价值因子可能解释收益。但它仍不代表价值因子必然可交易,还要看交易成本、换手、样本外。

## 常见误区

- `R^2` 高不代表预测未来好。
- p 值显著不代表经济收益足够大。
- 多试很多变量后挑显著结果,会产生数据挖掘。
