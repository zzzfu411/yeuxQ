# 数学补充 03: 时间序列数学基础

## 这一章解决什么问题

时间序列不是一堆独立数字,它有顺序。本章解释平稳性、自相关、随机游走、差分、AR、MA、ARIMA。

## 先用人话理解

如果一个人每天心情和昨天很像,这叫有自相关。如果一个醉汉每一步都随机走,位置会越走越飘,这像随机游走。股价常像位置,收益率更像每一步。

## 核心概念

- 平稳性: 均值、方差、自相关结构不随时间变。
- 自相关: 当前值和过去值的相关性。
- 随机游走: 当前值等于昨天值加随机冲击。
- 差分: 用变化量替代水平值。
- AR: 当前值由过去值解释。
- MA: 当前值由过去误差解释。

## 数学公式与推导

随机游走:

```text
Y_t = Y_{t-1} + epsilon_t
```

连续展开:

```text
Y_t = Y_0 + epsilon_1 + epsilon_2 + ... + epsilon_t
```

如果 `epsilon_t` 独立同分布,均值为 0,方差为 `sigma^2`,则:

```text
E[Y_t] = Y_0
Var(Y_t) = t sigma^2
```

推导方差:

```text
Var(Y_0 + sum epsilon_i)
= Var(sum epsilon_i)
= sum Var(epsilon_i)
= t sigma^2
```

所以随机游走不平稳: 方差随时间增加。

一阶差分:

```text
Delta Y_t = Y_t - Y_{t-1} = epsilon_t
```

差分后就可能平稳。这解释了为什么量化常研究收益率而不是价格。

AR(1):

```text
Y_t = phi Y_{t-1} + epsilon_t
```

若 `|phi| < 1`,冲击会逐渐衰减,序列可平稳。

MA(1):

```text
Y_t = epsilon_t + theta epsilon_{t-1}
```

ARIMA(p,d,q) 表示先差分 `d` 次,再用 ARMA(p,q) 建模。

## 放到 A 股量化里怎么用

- 价格通常不平稳,直接回归价格容易伪回归。
- 收益率更接近平稳,更适合统计检验。
- 波动率会聚集,这会影响风险控制。

## 常见误区

- 图上看起来有趋势,不代表趋势可交易。
- 差分能处理随机游走,但可能丢掉长期信息。
- ARIMA 不是金融预测圣杯,金融噪声很大。
