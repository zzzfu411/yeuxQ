# 数学补充 01: 概率、期望、方差

## 这一章解决什么问题

量化研究每天都在处理不确定性。收益率不是固定答案,而是随机变量。本章建立最基础的语言: 概率、期望、方差、协方差和相关系数。

## 先用人话理解

把股票明天收益想成一张成绩单还没公布的考试。概率描述每种成绩出现的可能性,期望描述平均能考多少,方差描述成绩有多不稳定。两个股票一起涨跌的程度,用协方差和相关系数描述。

## 核心概念

- 随机变量: 结果不确定的数,如明日收益率 `R`。
- 期望: 长期平均值,记作 `E[R]`。
- 方差: 围绕平均值的波动大小,记作 `Var(R)`。
- 协方差: 两个变量一起偏离均值的程度。
- 相关系数: 把协方差标准化到 `[-1, 1]`。

## 数学公式与推导

离散随机变量 `X` 取值 `x_i`,概率为 `p_i`,满足 `p_i >= 0` 且 `sum_i p_i = 1`。

期望:

```text
E[X] = sum_i p_i x_i
```

解释: 每个结果乘以出现概率,再求和。

方差:

```text
Var(X) = E[(X - E[X])^2]
       = E[X^2] - (E[X])^2
```

推导:

```text
E[(X - mu)^2]
= E[X^2 - 2mu X + mu^2]
= E[X^2] - 2mu E[X] + mu^2
= E[X^2] - 2mu^2 + mu^2
= E[X^2] - mu^2
```

其中 `mu = E[X]`。这个公式常用于计算波动率。

协方差:

```text
Cov(X, Y) = E[(X - E[X])(Y - E[Y])]
```

相关系数:

```text
Corr(X, Y) = Cov(X, Y) / (sqrt(Var(X)) sqrt(Var(Y)))
```

为什么要除以标准差? 因为协方差受单位影响。两个收益率用百分比或小数表示,协方差数值会变,但相关系数不变。

适用条件:

- 需要样本能代表总体。
- 极端值会严重影响均值、方差和相关系数。
- 金融收益经常厚尾,所以要配合稳健统计。

## 放到 A 股量化里怎么用

- 收益率均值估计预期收益。
- 收益率标准差估计风险。
- 相关系数估计两个股票或因子是否重复。
- RankIC 本质上也是一种相关性,只不过对排名计算。

## 常见误区

- 均值高不代表一定赚钱,如果波动也很大,体验可能很差。
- 相关为 0 不代表没有关系,可能只是没有线性关系。
- 历史相关性会变化,牛市和熊市中的相关结构可能不同。
