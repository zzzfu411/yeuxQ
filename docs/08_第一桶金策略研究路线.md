# 08 第一桶金策略研究路线

> 风险提示: 本项目不能保证稳定赚钱,也不能保证赚到一百万元。这里的目标是把“一百万元”拆成可计算、可审查、可拒绝的研究流程。
## 先把目标量化

如果从 10 万元到 100 万元:

- 5 年需要约 58.5% 年化。
- 8 年需要约 33.4% 年化。
- 10 年需要约 25.9% 年化。

这些都是很高的目标。系统必须先拒绝不现实路径,再寻找值得长期观察的候选策略。
生成资金目标计划:

```powershell
uv run python examples/run_goal_plan.py --starting-capital 100000 --target-capital 1000000 --years 8 --output-dir results/goal
```

输出:

- `capital_goal_plan.json/md`
- `market_regime.json/md`

## 当前 A 股市场假设
截至 2026-06-08 的研究假设:

- 市场更像结构性行情,不是全市场单边趋势。
- 科技、半导体、光通信、机器人等热点波动可能较大。
- 稳定复利优先级高于单一热点暴露。
- 低频、多因子、低波动、流动性约束、成本压力测试是默认路线。

这些假设不是买卖信号,只是策略筛选约束。

一键流水线会先生成 `data_gap_action_plan.json/md`、`candidate_hypotheses.json/md`、`candidate_experiment_queue.json/md`、`candidate_experiment_readiness.json/md`、`candidate_experiment_launch.json/md`、`candidate_experiment_completion.json/md` 和 `first_million_readiness.json/md`。数据缺口清单回答“现在还差哪些真实数据证据和 CSV 替换动作”; 候选假设回答“哪些候选值得被验证、需要哪些证据、什么条件自动降级”; 实验队列回答“真实数据通过后先跑哪些实验、如何证伪、何时停止”; 可运行性审查回答“现在是否允许开跑这些实验”; 启动计划回答“如果允许,首个候选实验应该在哪个固定目录、用哪组命令和证据运行”; 完成审查回答“启动计划要求的产物是否齐全且没有 BLOCK”。就绪卡片把这些 gate 压成首屏 PASS/WATCH/BLOCK。它们都不是收益承诺、不是策略排名,也不是实盘指令。

## 策略进入模拟盘的条件

候选策略至少需要:

- 年化收益接近或超过目标路径。
- 最大回撤低于预算。
- 夏普不低于观察线。
- 数据审计没有 BLOCK。
- 稳健性报告没有 BLOCK。
- 拒单率低。
- LLM 审查没有 BLOCK。
- 股票池拥有 point-in-time 成分和退市样本证据,不能把当前股票快照回填到历史时期。
- 连续 paper 观察必须来自 `run_paper_loop` checkpoint; 历史回测的 `research_execution_preview` 不计入观察天数。

如果这些条件不满足,系统应继续研究,不应提高资金。
## 推荐研究方向

先研究三类保守候选:

- 多因子核心组合: 动量、低波动、价值、质量、流动性综合。
- 低波动增强组合: 降低回撤,牺牲部分进攻性。
- 趋势过滤组合: 市场状态较差时降低仓位或暂停开新仓。

可以一次跑多个候选策略:

```powershell
uv run python examples/run_candidate_selection.py --config config/research.yaml --output-dir results/research/<timestamp> --starting-capital 100000 --target-capital 1000000 --years 8
```

当前候选池包括:

- `price_volume_defensive`: OHLCV-only 防守价量候选,适合先验证只有日线行情、暂无 PIT 财务数据的数据包。
- `core_multifactor`: 核心多因子。
- `defensive_low_vol`: 防守低波动。
- `momentum_quality`: 动量质量。
- `value_low_vol`: 价值低波动。
- `trend_filtered_core`: 趋势过滤核心多因子。
- `stable_universe_slow_signal_price_volume`: OHLCV-only wide quarterly slow-signal candidate using `long_momentum_120d_skip20d`, very low volatility, low volatility, and liquidity. It is a research-only structural turnover test after target-generation controls failed.
- `long_momentum_liquidity_monthly_price_volume`: OHLCV-only monthly component-ablation candidate using only `long_momentum_120d_skip20d` and liquidity after the stable slow-signal diagnostics suggested low-volatility dilution. It is research-only and cannot bypass source QA, paper, human approval, or broker gates.
- `liquidity_neutral_momentum_guard_price_volume`: OHLCV-only guarded liquidity-neutral momentum candidate using residualized long momentum, very low volatility, quarterly rebalance, and defensive-or-worse exposure scaling. It is a research-only test of liquidity dependency and defensive-window damage, not paper approval.
`candidate_selection` 会记录每个候选的 `data_dependency_status`。如果数据包缺少 PIT 财务字段,带估值、质量依赖的候选会被降级,不能与 OHLCV-only 候选平权竞争。

`candidate_selection.json/csv` also records `capital_goal_fit_review` for each
candidate. This review compares annual return against the one-million path,
drawdown against the budget, candidate walk-forward worst windows, Sharpe,
reject rate, and turnover. `top_candidate` can remain the highest research
rank, but `selected_candidate` is empty when the top candidate is still BLOCK
for the capital goal.

把本次候选结果追加到长期策略档案:

```powershell
uv run python examples/update_strategy_registry.py --report-dir results/research/<timestamp>
```

输出:

- `results/strategy_registry/strategy_registry.json`
- `results/strategy_registry/strategy_registry.md`
- `strategy_registry_snapshot.json/md`

策略档案使用 v3 合同记录每个候选的真实观察、排除观察、demo 观察、PASS/WATCH/BLOCK、收益、回撤、夏普和晋级资格。只有 provenance、selection safety、benchmark、multiple-testing 与 prospective trial binding 全部通过的观察才计入真实晋级统计。
晋级资格只看真实数据观察:

- demo-only 历史不能晋级。
- 需要至少 3 次真实数据观察。
- 需要至少 2 次真实数据 PASS。
- 真实历史不能出现 BLOCK。
- benchmark、multiple-testing 和 trial registry review 必须完整 PASS，旧 v2 registry summary 不能晋级。
- 平均回撤和拒单率必须在预算内。

再对长期 registry 做晋级审查:

```powershell
uv run python examples/review_strategy_promotions.py --registry results/strategy_registry/strategy_registry.json --output-dir results/strategy_registry --starting-capital 100000 --target-capital 1000000 --years 8
```

输出:

- `strategy_promotion_review.json`
- `strategy_promotion_review.md`

晋级审查里的 `PASS` 只表示“值得继续 paper-stage 深挖”,不是实盘资格。
不要从一开始就做:

- 单一热点追逐。
- 杠杆。
- 高频。
- 小市值极端集中。
- LLM 直接选股。

最终目标不是找到一次暴富,而是找到可以长期审查、长期复盘、长期控制回撤的候选策略。
